# Dr. Pill
Dr. Pill is a medication tracking app that is designed specifically for older adults.

# Instructions
To run this project locally, follow these steps:

### 1. Start the Backend
Open command prompt in the root project directory and run the following commands:
```bash
cd backend
npm install
npm start
```

### 2. Run the Flutter Application
In a separate command prompt in the root project directory, run the following commands:
```bash
flutter pub get
flutter run
```
